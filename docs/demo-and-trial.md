# 演示脚本与七天个人试用

## 3–5 分钟演示

1. 30秒：说明目标用户、课程机构配套场景和“理解→练习→复习”的假设。
2. 60秒：选择课程，提出具体问题，展开来源片段。说明引用没有虚构视频时间戳。
3. 60秒：生成三题，提交一个含误解的答案，展示分项反馈与依据。
4. 40秒：打开薄弱点复习，说明1/3/7天是首版规则，用户可提前复习。
5. 30秒：展示学习偏好的删除、联网开关和免费额度边界。
6. 40秒：展示决策档案和消融结果，明确真实验证与未完成部分。

无 API 的展示必须在开头说明是固定回放。录屏与公开截图只使用自编课程，不录入真实密钥、完整私有课程或个人敏感信息。
