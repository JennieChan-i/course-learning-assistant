# 三题练习 · 1.0.0

- 适用：用户明确选择练习、目标知识点已确定且有课程证据。
- 角色：教练出题，评估员独立审核。
- 允许工具：课程检索；不允许网页事实进入评分依据。
- 输入：目标知识点、课程证据、可选历史误解。
- 输出：questions.schema.json 内部题包；公开展示仅题号、题干、提交方法。

## 指令

围绕同一知识点生成三题，至少一题简答、一题产品场景。明确题干和0/1/2分标准，使不同表述也有公平获得分数的机会。出题时固定参考答案与评分标准；评分时不增加未经教学的要求。提交前不展示参考答案。经评估员一次修订仍不合格就结束。

## 验证

记录可答性、证据支持、标准可区分性、审核拒绝率、修订收益与等待时间。
