# 2026-10-26 工作空间默认模型变更

用户告知并提供截图：系统推理模型改为 `XingChenAGI/Xing4.0-29B`，Embedding 改为 `BAAI/bge-m3`，Rerank 改为 `BAAI/bge-reranker-v2-m3`；语音转文字为 `FunAudioLLM/SenseVoiceSmall`，文字转语音为 `qwen3-tts-flash`。这些是用户报告的默认设置，未重新登录核查或调用。

教程的业务流程、角色、代码和变量协议可沿用，但模型配置需要核对：

1. 现有 LLM、分类器和 Agent 节点可能仍显式绑定 `kimi-k3`。在节点里确认模型，不能只看工作空间默认值。
2. 原完整库曾用 `qwen3.7-text-embedding-flash` 索引。要用 `bge-m3`，需确认目标库完成重新向量化，并让 Q01、P00、检索工具选择同一目标库；不能混用不同模型生成的向量。
3. Xing 模型的原生工具调用、结构化输出、上下文和输出上限尚未验证。旧 Kimi 的 temperature 报错是历史案例，不是新模型的已知限制；旧预算也需按新服务支持设置。
4. 有 rerank 默认值不代表已启用。仍可沿用无模型 rerank 的混合权重基线；若启用新 rerank，需另测成本、延迟和质量。
5. 首版语音仍关闭。默认模型更改不会自动启用新功能，也不会修改本地项目的 .env 或模型目录。

交互手册及逐节点参数保留旧教学配置，供对照与理解；它们不是实时读取云端的页面。给 ChatGPT 提问时，应把本说明与[上下文包入口](../../chatgpt-context/00-先读我与开场提示词.md)一并提供，最新模型信息优先于旧绑定。
