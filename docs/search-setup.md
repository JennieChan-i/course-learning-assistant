# 我如何配置免费搜索 MCP

我选择 Tavily 官方 MCP，只开放基础搜索，学习工作台默认关闭联网。2026-10-25 核查时，注册的 Researcher 免费账户每月提供 1,000 credits，无需信用卡；基础搜索每次消耗 1 credit。条款以[官方价格](https://www.tavily.com/pricing)和[额度说明](https://docs.tavily.com/documentation/api-credits)为准。

## 获取并填写密钥

1. 打开 [Tavily 控制台](https://app.tavily.com/)，按页面提示注册、登录，保留 Researcher / Free 套餐。
2. 在 API Keys 区域复制已有密钥；没有密钥时点击“＋”创建。名称可填 `course-learning-assistant`，如提供类型选择则选 Development，如提供月度限制则可设为300。参见[官方教程](https://help.tavily.com/articles/9170796666-how-can-i-create-an-api-key)。
3. 在项目根目录 `.env` 的 `TAVILY_API_KEY=` 后填写完整密钥，不更改 LLM 配置，不重复添加同名配置。
4. 停止并重新启动本项目后端。设置页应显示“已配置密钥”，聊天时主动开启“联网补充”，再提出需要时效资料的问题。

密钥只留在本地 `.env`。我不把密钥放进截图、聊天、运行报告或 GitHub。无需开通付费套餐或按量付费。

## 三种限额的区别

| 限制 | 来源 | 我的处理 |
|---|---|---|
| 每月300次请求 | 本项目的本地保护上限 | 发出请求前预留计数，失败请求也计入本地上限；这不是服务商赠送额度 |
| 每月1,000 credits | 注册账户的免费套餐 | 以控制台实际余额为准；本项目只用 basic 搜索 |
| 免密访问限制 | Tavily 服务端的独立限制 | 不保证有300次；官方未在所核查页面承诺固定次数 |

免密访问是可选开发方式（`TAVILY_ALLOW_KEYLESS=true`），默认关闭。没有密钥时默认降级为课程内回答。免密与带密钥访问的区别见[官方说明](https://docs.tavily.com/documentation/keyless)。

## 本次真实验证

免密 MCP 的初始化与工具发现成功，但首次正确参数的搜索返回额度限制；这不能解释成“使用者已经用完300次”。使用者配置自己的免费密钥后，经官方 MCP 的初始化、工具发现、基础搜索，成功取得5个外部结果。验证使用独立学习数据库，不写入正式学习历史；所有应用内搜索使用 `runtime/search-budget.sqlite3` 的项目共享计数，切换课程库或清空学习记录不会重置。此前三次已记录的带密钥集成搜索已迁入共享计数。服务商账户也记录实际调用。

我根据 MCP 实际发现的工具 Schema 过滤参数，并固定 `search_depth=basic`、`max_results=5`。对不支持的字段不强行发送；不调用抓取、研究或付费备用工具。密钥、网络或额度有问题时显示未完成核查，不能声称已联网确认。
