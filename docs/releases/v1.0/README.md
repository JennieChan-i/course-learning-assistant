## 1. 用户问题与商业假设

我聚焦正在学习AI产品经理课程的转岗学员。待验证的问题是：听过概念却难以复述和应用；不知道作答遗漏在哪里；课程内容与最新信息混杂；提问后缺少复习。

我的价值主张是“有依据地答疑 → 用作答检验理解 → 根据误解复习”。课程机构是潜在付费方，可能关心重复答疑负担和课后支持；目前没有访谈、合同、收入、节省工时或对照学习效果的证据。这些是商业假设。

我选择单用户Windows本机运行，以现有课程和本人试用控制范围。收费、多租户、机构后台、通用文件上传、语音、视频播放、视频时间戳和完整模拟面试不在本版范围。

## 2. 用户流程与交付范围

| 用户任务 | v1.0行为与依据 | 适用边界 |
|---|---|---|
| 理解课程 | 选择单课/全部课程，提问和追问；回答附可打开的整理文本片段 | 有来源编号不等于主张被证据支持；不虚构视频定位 |
| 检验理解 | 每轮3题，教练出题、评估员审核，最多修订一次；提交前隐藏参考答案 | 可运行不等于题目整体质量已验收 |
| 获得反馈 | 三维各0–2分、具体遗漏、误解、来源和教练建议 | 形成性反馈，不能视为能力认证或考试预测 |
| 复习薄弱点 | 依据有效作答更新，按知识点合并，使用1/3/7天规则 | 这是透明规则，尚未证明是最优个性化算法 |
| 管理记忆 | 保存明确偏好和作答证据；可修改、删除；删除后停止注入旧上下文 | 提问、阅读或点击“懂了”不作为掌握证据 |
| 核查时效信息 | 用户开启联网后，通过Tavily官方MCP基础搜索；支持站点限定 | 只增补外部证据，不自动覆盖课程库或参与课程评分 |
| 应对失败 | 显示未核查/失败，支持停止任务；无效成绩不写入，成功提交幂等 | 取消不能撤回服务商已处理的调用；网络与账户仍可能受限 |
| 开展开发者评测 | 独立审阅页、版本化本地标注、检查点、显式失败复测 | AI候选标签与模型间一致性不能冒充人工gold |

界面为左侧课程导航、中央学习区和来源详情，支持明暗主题与窄屏折叠。公开展示使用自编样例。当前真实资料为14节课、877个父片段、2,243个检索子片段；原文、衍生索引、会话和密钥留在本地。

## 3. 关键取舍及其产品意义

| 我选择的方案 | 为什么这样做 | 接受的成本与重新评估条件 |
|---|---|---|
| 两个Agent，普通问答只用教练 | 让教学与评分拥有不同任务和上下文，控制协作开销 | 同模型可能共享偏差；人工对照若无质量收益，应收缩分工 |
| small中文embedding＋base reranker | 适应RTX 5060 Ti 8GB，先建立可运行轻量基线 | 更大模型只在任务开发集增益与资源目标同时达标时切换 |
| BM25＋向量＋RRF＋重排 | 同时覆盖专有词和口语表达，再判断相关性 | 链路复杂度增加；测试集已有重排下降，不能默认重排有益 |
| 父子切分、真实tokenizer检查 | 兼顾短模型输入和完整引用追溯 | 增加版本与偏移维护；切分边界需要单独分析 |
| 本地SQLite＋Qdrant | 减少服务部署和云依赖，适配单人学习 | 不支持多进程独占同一索引；扩大规模再评估服务模式 |
| 三个版本化应用Skill | 让概念解释、练习、复习各有明确指令和约束 | Skill不自动获得工具权限，不执行任意下载脚本 |
| 确定性后端负责长期状态写入 | 防止模型绕过评分、改成绩或重置预算 | 保留事务、幂等和删除边界测试，不能只依赖提示词 |
| 一个可选搜索MCP | 为课程不足和时效问题引入外部资料 | 项目月度上限300次是保护规则，不是服务商赠送额度 |
| 仅教练使用low推理覆盖 | 同模型小样本显示等待缩短，评分保留默认力度 | 质量未获独立人工确认，仍有长尾；回归失败或质量下降时撤销 |
| 保留代码版，Dify仅作备选设计 | 当前代码已覆盖精确范围、引用校验、状态写入与预算 | Dify教程不等于已迁移；有维护或用户价值收益再验证 |

实际技术栈、调用链与权限见[架构](../../architecture-overview.md)。非敏感配置、模型revision、Skill版本和文件指纹见[基线清单](baseline.json)。

## 5. 验收状态与首要风险

**可进入个人内测；正式质量与性能验收未完成。**

| 验收项 | 目标 | 当前判断 |
|---|---|---|
| 父片段Recall@10 | 可回答题≥90% | 公开候选与私有工作表都需人工审阅；正式结论待验证 |
| 事实主张证据支持率 | ≥90% | 需逐主张核对，不能用编号校验替代 |
| 无答案正确处理率 | ≥90% | 已执行边界题，但人工裁定待完成 |
| 评分与人工总分差≤1 | 比例≥85% | 40份样例暂无独立人工gold |
| 预热单并发检索＋重排P95 | ≤1.5秒 | 小样本时延观察达目标；正式课程代表性尚不足 |
| 首次有效内容/完整回答P95 | ≤8秒/≤25秒 | 尚未完成代表性单并发验收，已有观测显示明显长尾 |
| 学习价值 | 真实任务有帮助，误解反馈可执行 | 七天实际试用尚待完成；没有学习效果因果证据 |
| 商业价值 | 机构真实需求和付费意愿 | 尚无访谈或试点证据 |

首要风险是回答/评分的语义质量没有人工真值、等待时间影响闭环完成，以及原课程可能存在转写或时效问题。单用户本地运行没有公网认证、多租户或机构部署能力。[迭代计划](iteration-plan.md)给出了每项风险的验证和退出条件。

## 6. 我接下来如何推进

先用真实学习任务完成人工走查和首批标注，再按失败原因修复并复测，开展本人真实试用，同时分解冷启动、工具、检索、模型和输出的耗时。机构访谈和商业试点在个人可用性证据之后推进。后续功能是否进入版本，取决于证据与收益，而不是是否能再展示一种AI技术。
